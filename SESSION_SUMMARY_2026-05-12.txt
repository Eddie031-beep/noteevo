================================================================================
1. PRIMARY REQUEST AND INTENT
================================================================================

Building NoteEvo, a Notion-like notes app. The session started with integrating
NoteEditor into the dashboard, then progressively added:
- favorites/trash functionality
- a UIStore for view navigation
- tag system (TagInput component with create/add/remove)
- full-text search via Supabase RPC
- image upload via Supabase Storage
- a TipTap text extraction utility

The user provided exact code for most files and asked for them to be
created/applied verbatim, with occasional fixes for lint errors and runtime
issues.

================================================================================
2. KEY TECHNICAL CONCEPTS
================================================================================

- Next.js 16.2.6 App Router (server + client components, Turbopack)
- Supabase client-side SDK (auth, DB queries, storage, RPC calls)
- Zustand stores (notebookStore, noteStore, tagStore, uiStore)
- TipTap v3 editor (SSR-safe with `immediatelyRender: false`, JSON content format)
- Tailwind CSS v4 (CSS-based config via `@import "tailwindcss"`, no tailwind.config.ts)
- @tailwindcss/typography plugin (added via `@plugin` directive in globals.css)
- React uncontrolled inputs with refs (to avoid setState-in-effect lint errors)
- `syncedNoteIdRef` pattern to guard useEffect re-runs on note ID change only
- `key` prop for forced component remount (TagInput resets when note changes)
- Supabase full-text search via `.rpc('search_notes', { search_query })`
  (replaced textSearch)
- Supabase Storage for image uploads to `note-images` bucket
- Click-outside detection via `mousedown` event on `document`
- `react-hooks/set-state-in-effect` and `react-hooks/exhaustive-deps` ESLint rules

lib/supabase/search.ts (NEW - final RPC version)
--------------------------------------------------------------------------------
  export async function searchNotes(query: string): Promise<Note[]> {
    if (!query.trim()) return []
    const supabase = createClient()
    const { data, error } = await supabase
      .rpc('search_notes', { search_query: query.trim() })
    if (error) throw new Error(error.message)
    return (data ?? []) as Note[]
  }

4. ERRORS AND FIXES
================================================================================

1. TipTap SSR hydration error:
   "SSR has been detected, please set `immediatelyRender` explicitly to `false`"
   FIX: Added `immediatelyRender: false` to `useEditor({...})` options.

2. `react-hooks/set-state-in-effect` (error):
   `setTitle` called synchronously in useEffect.
   FIX: Removed `title` state, using uncontrolled input with `titleRef`, and
   directly setting `titleRef.current.value` in the effect.

3. `react-hooks/exhaustive-deps` (warning):
   `editor` and `selectedNote` missing from useEffect deps.
   FIX: Added them to deps array but guarded with
   `syncedNoteIdRef.current === selectedNote.id` check to prevent re-syncing
   on store updates mid-type.

4. Accessibility lint error on Star button in NoteEditor:
   "Buttons must have discernible text. Element has no title attribute"
   FIX: Added `title={selectedNote?.is_favorite ? 'Quitar de favoritos' : 'Añadir a favoritos'}`.

5. Accessibility lint error on clear search button in Sidebar:
   "Buttons must have discernible text. Element has no title attribute"
   FIX: Added `title="Limpiar búsqueda"`.

6. File modified error on Sidebar.tsx write:
   Tool detected file was modified externally.
   FIX: Had to read first then write.

7. TagInput import unused warning:
   After adding import, had to also add JSX usage in NoteEditor.

================================================================================
5. PROBLEM SOLVING NOTES
================================================================================

setState in useEffect pattern:
  Solved by switching to uncontrolled input + ref manipulation, which is the
  React-recommended approach for syncing external data to DOM without cascading
  renders.

Note switching without resetting mid-type:
  Solved by `syncedNoteIdRef` — effect includes all deps in array but skips
  sync if note ID hasn't changed.

TagInput remount on note change:
  Solved cleanly with `key={selectedNote.id}` — no useEffect needed for reset.

Global tag loading:
  Tags loaded once in Sidebar (always mounted) via useEffect, stored in
  tagStore, consumed by any TagInput instance.

Search replacing textSearch:
  First implementation used Supabase `textSearch` on `search_vector` column;
  replaced with `supabase.rpc('search_notes', ...)` for a Postgres function
  approach.
